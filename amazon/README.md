# Amazon Fine Food Reviews

This directory contains the Amazon real-data analysis and the synthetic
experiments based on the covariance structure of the Amazon Fine Food Reviews
data.

## Setup

The analyses require R and the following packages:

- Data manipulation: `dplyr`, `readr`, `purrr`, and `tibble`
- Simulation and parallelization: `MASS`, `future`, `future.apply`, and
  `progressr`
- HDF5 input: `rhdf5`
- Empirical Bayes methods: `REBayes`, `ebci`, and `Rmosek`

The NPMLE calculations require a working MOSEK installation and license through
`Rmosek`. Configure the MOSEK license before running the experiments.

The processed input file is included at:

```text
amazon/data/amazon_review.h5
```

## Running the experiments

The R scripts use paths relative to `amazon/scripts/`. Run the following
commands from that directory, not from the repository root.

The scripts run simulations in parallel. Replace `4` with any positive number
of workers suitable for the available machine.

### Amazon real-data experiment

From the repository root:

```bash
cd amazon/scripts
Rscript amazon_review.R --num-workers=4
cd ../..
```

The script runs 200 random splits for each
`alpha` in `{0.05, 0.10, 0.20, 0.30}` and writes:

```text
amazon/results/amazon_real.csv
```

### Paper-plotting inputs

Generate the Amazon distribution-fitting and diagnostic data separately from the
repeated real-data experiment:

```bash
cd amazon/scripts
Rscript amazon_plotting_data.R
cd ../..
```

The script uses a fixed split with seed 3 and writes:

```text
amazon/results/amazon_bias_se_pt.csv
amazon/results/amazon_param_pt.csv
amazon/results/amazon_npmle_pt.csv
amazon/results/amazon_bias_nuisance_diagnostics.csv
```

### Synthetic Amazon experiments

From the repository root:

```bash
cd amazon/scripts
Rscript synthetic_amazon.R --num-workers=4
cd ../..
```

The script runs 500 replications for every setting in three experiments:

1. Normal bias distributions with varying bias variance
2. Two-point bias distributions with varying support
3. Normal target distributions with varying target dispersion

The corresponding outputs are:

```text
amazon/results/synthetic_normal.csv
amazon/results/synthetic_twopoint.csv
amazon/results/synthetic_theta.csv
```

## Paper-plot inputs

Running the Amazon real-data, synthetic-data, and plotting-data scripts
generates the following paper-plot inputs under `amazon/results/`:

- `amazon_real.csv`: real-data confidence-interval comparison
- `synthetic_normal.csv`: synthetic normal-bias experiment
- `synthetic_twopoint.csv`: synthetic two-point-bias experiment
- `synthetic_theta.csv`: synthetic varying-target experiment
- `amazon_bias_se_pt.csv`: estimated PT biases and standard errors
- `amazon_param_pt.csv`: fitted parametric bias distribution
- `amazon_npmle_pt.csv`: fitted NPMLE bias distribution
- `amazon_bias_nuisance_diagnostics.csv`: diagnostic plotting data

The last four files are generated by `amazon_plotting_data.R` and are consumed
by the cross-application and diagnostic plots.
